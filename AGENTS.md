# Codex instructions

This repository contains a Remotion vertical video project.

## Goal
Preview and iterate on the `FlatShop` composition. Keep the visual style cohesive: clean flat-vector illustration, bold dark outlines, soft warm palette, Indian/social-media explainer sensibility, not childish/cartoonish.

## Run
1. `npm install`
2. `npm run dev`

This opens Remotion Studio. Select the `FlatShop` composition to watch the video.

## Render
Run `npm run render` to export `out/flat-shop.mp4`.

## Editing guidance
- Prefer SVG/React vector shapes or imported SVG assets.
- Keep 1080x1920 vertical format.
- Use smooth, restrained motion; avoid bouncy gimmicks.
- Keep characters and backgrounds visually consistent.
- When asked to improve a scene, edit the repo and verify in Remotion Studio rather than only returning code snippets.
